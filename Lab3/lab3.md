# Лабораторна робота №3: Маніпулювання даними SQL (OLTP)

Ця робота є продовженням розробки бази даних для **Тату-студії**. На основі схеми, розробленої в Лабораторній №1, було виконано тестування бази даних за допомогою операцій DML (Data Manipulation Language).

## 1. Заповнення даних (INSERT)
Для перевірки працездатності системи було додано:
- 3 тату-майстри з різними спеціалізаціями.
- 5 клієнтів (з урахуванням вікового обмеження 18+ та медичних нотаток).
- 5 сеансів запису з фіксацією дати та ціни.
- Опис ескізів та облік розхідних матеріалів на складі.

## 2. Аналіз та вибірка (SELECT)
Виконано наступні запити:
- Отримання списку персоналу для адміністратора.
- Фільтрація дорогих сеансів (понад 3000 грн) для виявлення найбільш прибуткових робіт.
- Отримання медичної інформації про клієнта перед початком сеансу (безпека).

## 3. Оновлення та видалення (UPDATE/DELETE)
Протестовано реальні сценарії:
- **UPDATE:** зміна контактних даних клієнта та оновлення залишків на складі після закупівлі товару.
- **DELETE:** скасування сеансу за його ідентифікатором та видалення помилкових записів про використання матеріалів.
