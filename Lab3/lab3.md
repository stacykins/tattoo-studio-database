# Лабораторна робота №3: Маніпулювання даними SQL (OLTP)

У цій роботі протестовано базу даних тату-студії за допомогою операцій маніпулювання даними (DML).

## Опис виконаних запитів

### 1. Отримання даних (SELECT)
- **Запит:** Вибірка сеансів з ціною > 1800 грн.
- **Мета:** Фільтрація найбільш прибуткових замовлень для звітності.
- **Очікуваний результат:** Список сеансів Олексія та Марії.
- **Результат:** Запит повернув 2 рядки.

### 2. Оновлення даних (UPDATE)
- **Запит:** Оновлення `medical_notes` для клієнта №1 та зміна ціни сеансу №3.
- **Мета:** Перевірка можливості редагування записів при зміні обставин (зміна стану здоров'я клієнта або умов роботи).
- **Очікуваний результат:** Поля в таблицях `Clients` та `Sessions` зміняться на нові значення.
- **Результат:** Дані успішно оновлені.

### 3. Видалення даних (DELETE)
- **Запит:** Видалення сеансу №2.
- **Мета:** Перевірка роботи каскадного видалення (`ON DELETE CASCADE`).
- **Очікуваний результат:** При видаленні сеансу автоматично мають зникнути пов'язані з ним записи в таблицях `Tattoos` та `Material_Usage`.
- **Результат:** Рядок видалено, цілісність бази даних збережена.
